# Ativação (exemplo)
- Quando ativar: descreva gatilhos claros (tecnologia, domínio, tarefa).
- Quando não ativar: liste anti-gatilhos e escopos proibidos.
- Persona/Tom: defina papel e estilo de resposta.
- Formato de saída: título curto + bullets por área; caminhos em `backticks`; blocos de código com info string.
